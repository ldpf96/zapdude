ℹ️Acerca de ZapZap

Cliente de escritorio de WhatsApp Web escrito en Rust (Tauri 2 + WebView2).

Inspirado en ZapZap de Rafael Tosta (@rafatosta) — trabajo original en Python/GTK, licencia GPL-3.0.

Esta reescritura se distribuye bajo AGPL-3.0 como obra derivada (sección 13). Crédito obligatorio al creador original.

  • ✅ Multi-cuenta real: perfiles WebView2 aislados por cuenta
  • ✅ Notificaciones de todas las cuentas en un dispositivo
  • ✅ API local para agentes de IA (REST + SSE + webhook HMAC)
  • ✅ Llamadas voz/vídeo y compartir pantalla (identidad Chrome)
  • ✅ Bandeja del sistema para cambiar de cuenta rápidamente
  • ✅ Instalador Windows (NSIS, sin privilegios de admin)
Crédito: Rafael Tosta — https://github.com/rafatosta/zapzap
