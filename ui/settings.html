API local para automatización

Permite que personas o agentes de IA controlen tus cuentas de WhatsApp desde la propia máquina. La API solo es accesible desde tu equipo (127.0.0.1).

http://127.0.0.1:29977/api
Se envía en el encabezado X-API-Key
Recibe los eventos en tu servidor
Firma HMAC-SHA256

Conectar un agente de IA

El agente usa la API local para leer chats, abrir conversaciones y enviar mensajes por cualquiera de tus cuentas. Endpoints disponibles:

GET /api/status?account=<id> — estado de la sesión
GET /api/chats?limit=20&account=<id> — lista de chats
POST /api/message — {"account","phone","message"}
POST /api/open-chat — {"account","phone","text?"}
GET /api/events/stream — eventos en vivo (SSE)
GET|POST /api/webhook — receptor de eventos

Todas las peticiones requieren el encabezado X-API-Key. Los eventos llegan etiquetados con la cuenta que los originó.
