Agente de IA

El agente usa la API local para leer chats, abrir conversaciones y enviar mensajes por cualquiera de tus cuentas. Endpoints:

GET /api/status?account=<id>
GET /api/chats?limit=20&account=<id>
POST /api/message — {"account","phone","message"}
POST /api/open-chat — {"account","phone","text?"}

Todas las peticiones requieren X-API-Key. Los eventos llegan etiquetados con la cuenta que los originó.
